## 📌 Project Introduction
This project focuses on Data Quality Analysis (DQA) and end-to-end data pipelines. Using SQL Server and Power BI, I extracted an intentionally messy e-commerce dataset from Kaggle, programmatically resolved data anomalies, and transformed it into a clean, business-ready repository for corporate reporting.

## 🛠️ Toolkit
* **DBMS:** MySQL
* **Client:** MySQL Workbench
* **Data Visualization:** PowerBI
* **Spreadsheets:** Excel

## 📂 Project Structure
* `README.md`: An introduction to the project.
* `sales_dashboard.png`: An image of the dashboard from PowerBI.
* `/Datasets`: Contains the raw and cleaned dataset.
* `/Queries`: Contains .SQL files that shows the process of auditing.
* `/Findings`: Contains .CSV files that shows results from queries.
